# UPVC Visualizer - NoiseGard Premium

Versi aman dengan Netlify Functions.

## Cara pakai
1. Upload folder ini ke GitHub
2. Deploy di Netlify
3. Di Netlify > Site settings > Environment variables, tambahkan:
   GEMINI_API_KEY = [API key kamu dari Google AI Studio]
4. Deploy ulang

Frontend memanggil /api/enhance dan /api/generate, key tidak terlihat di browser.
